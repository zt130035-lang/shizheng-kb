# 小题错因跟踪规范

批改不是一次性给出答案。对同一考生，系统应记录高频失分原因，并把修改建议转换为下一次可验证的训练任务。

## 每次小题批改的最小记录

| 字段 | 说明 |
| --- | --- |
| 题型 | 概括归纳、综合分析、提出对策、应用文等 |
| 原文位置 | 对应答案中的句子、要点或段落 |
| 问题标签 | 使用 [[问题标签/问题标签索引]] 的标准标签 |
| 错因类型 | 材料定位、分类归纳、逻辑分析、对策路径、任务格式、语言规范 |
| 修改动作 | 本次应补写、删减、重组或替换什么 |
| 复练状态 | 待二刷、已复练、已掌握 |

## 错因类型

- **材料定位**：没有找到或误读材料中的关键主体、对象、限制条件。
- **分类归纳**：同类信息未合并，或把问题、原因、对策混写。
- **逻辑分析**：没有完成释义、因果、影响或结论回扣。
- **对策路径**：措施缺少主体、对象、动作或执行路径。
- **任务格式**：应用文身份、对象、目的、语体或必要格式不匹配。
- **语言规范**：概念不准、句式混乱、表达重复或字数不合要求。

## 复练规则

1. 每次批改只选一到两个高频标签进入复练，避免将所有问题都列为任务。
2. 二刷题应尽量保持同题型、同错因，但更换材料主题。
3. 连续两次能自行修正同一错因，可标为“已掌握”；仍出现则保留“待二刷”。
4. 错因记录用于个性化训练，不得替代对当前题目的材料评分。

## 小程序输出

批改结果末尾增加“下一次训练”字段：

> 本次优先复练：提出对策题的“主体 + 路径”补全。下一题先用一句话写明“谁通过什么机制解决什么问题”，再展开作答。
