# 综合分析题评分标准

## 核心任务

综合分析不是罗列观点、原因和对策，而是解释题目中的一句话、现象或做法，并建立材料事实与结论之间的关系。

## 评分维度

| 维度 | 检查重点 |
| --- | --- |
| 观点 | 是否准确解释对象的含义或作出明确判断 |
| 依据 | 是否使用材料中的事实、主体或矛盾支撑判断 |
| 分析 | 是否说明原因、机制、影响或条件 |
| 结论 | 是否回应题目对象，并形成评价、启示或对策方向 |
| 表达 | 是否层次清楚、表述准确、符合字数要求 |

## 推荐作答闭环

1. **释义或判断**：说明题目对象是什么、该如何理解。
2. **材料分析**：从原因、表现、影响中选择与题目直接相关的内容展开。
3. **结论回扣**：得出评价、启示或解决方向，不能突然引入无关观点。

题目明确要求“谈理解”时，优先完成释义与分析；题目明确要求“评价现象”时，优先完成判断、原因和影响。不要机械套用“是什么、为什么、怎么办”。

## 常见失分与修改动作

| 问题 | 标签 | 修改动作 |
| --- | --- | --- |
| 只复述题干 | `内容/概括不准`、`逻辑/论证不足` | 补出对象的实质含义，并连接材料事实 |
| 原因、影响、对策并列堆放 | `结构/层次混乱` | 按“判断→分析→结论”重组，每层只承担一个功能 |
| 案例出现后没有解释 | `论证/案例无分析` | 在案例后补“这说明……因此……”的机制解释 |
| 结论脱离材料 | `内容/材料脱离` | 改用材料中的主体、问题和条件限定判断范围 |

## 批改输出

每项高优先级问题必须标注原文位置、问题标签、失分原因和局部替换句。没有题干或材料时，只能评价论证形式，不能断言内容要点是否得分。

## 方法补充

词句解释题优先检查“总体释义—展开解释—补充对策或总结”；正面词句重点看做法、意义、成效，负面词句重点看问题、危害、原因。观点和现象分析仍须回到“判断—依据—分析—结论”闭环。详见[[评分标准/申论100题-方法增补]]。
