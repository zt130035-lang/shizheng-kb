# 提出对策题评分标准

## 核心任务

对策必须针对材料中的具体问题，具备执行主体、行动内容和实施路径。价值口号可以概括方向，不能代替得分对策。

## 对策完整度

每条对策按以下要素检查，基础对策至少具备前两项，重点对策尽量写全：

| 要素 | 要回答的问题 |
| --- | --- |
| 主体 | 谁来负责或协同执行？ |
| 对象 | 针对什么问题、群体或场景？ |
| 动作 | 具体建立、整治、培训、公开或服务什么？ |
| 路径 | 通过什么机制、流程、资源或载体落实？ |
| 结果 | 解决什么问题、形成什么效果？ |

## 批改顺序

1. 将考生每条对策与材料问题一一对应。
2. 判断是否遗漏重要问题，或用一条笼统对策覆盖多个不同问题。
3. 标出缺少主体、对象或路径的对策。
4. 检查对策是否可行、是否超出材料允许的推断范围。
5. 按“主体 + 动作 + 路径 + 结果”给出局部改写。

## 改写示例

原文：加强宣传，提高群众意识。

改写：由社区和物业在高频问题发生前，通过楼栋宣讲、线上提醒和反馈公示明确办理流程，引导居民及时提交诉求，减少因信息不对称造成的重复投诉。

说明：补充了主体、场景、动作、路径和目标；具体措施仍须以题目材料为依据。

## 高风险问题

- 把“加强、完善、推进、提升”直接当作完整措施。
- 对策与材料问题没有对应关系。
- 同一对策反复换词，遗漏关键问题。
- 用未经材料支持的政策、资金或机构安排填充答案。

## 方法补充

材料中的对策、建议和成功经验可以反向校验问题覆盖；批改时按“问题对应→主体动作→实施路径→预期结果”逐条核对，避免只把“加强、完善、提升”当成完整措施。详见[[评分标准/申论100题-方法增补]]。
