# 申论批改小程序前端

基于 Flask 后端的申论批改微信小程序(微信原生小程序)。

## 已实现功能

- **图片批改**:相册一次选择最多 9 张作文图片,按顺序 OCR 识别后批改/润色;单张走快速视觉批改。
- **文本批改**:粘贴申论文本,按知识库评分规则打分,输出逐段批注与修改建议。
- **辅助写作**:根据题目生成示范申论、文章润色、范文对比。
- **整套批改**:上传试卷材料(PDF/Word/图片/粘贴文本)+ 各题作答,逐题核对材料要点、估算评分、生成参考答案;支持填写官方参考答案和分值;结果可导出 Word/PDF。
- **我的**:本机批改记录查看、复制、清空。

## 导入方式

1. 启动后端:`cd D:\下载\HTML\shizheng_kb && python server.py`
2. 微信开发者工具导入 `miniprogram` 目录。
3. 默认接口地址 `https://shizheng-kb.onrender.com`;本地调试可在工具中修改本地缓存 `BASE_URL` 为 `http://127.0.0.1:5678`(并勾选"不校验合法域名")。
4. 上线前:在微信公众平台配置 request/uploadFile 合法域名,并将 `project.config.json` 的 `urlCheck` 改为 `true`。

## 说明

- 用户数据(批改记录)保存在本机 storage;错题/收藏/学习记录按设备匿名 ID(`X-User-Id`)与后端隔离。
- 时政新闻、题库、收藏、知识问答等页面已从代码中移除(后端接口仍保留)。
